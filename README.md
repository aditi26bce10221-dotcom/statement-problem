Tic Tac Toe is a simple two-player game where players take turns marking spaces on a 3×3 board with X and O. The main problem is to create a simple computer-based version of the game that allows two players to play easily and checks the game rules automatically.

The project aims to develop a Python-based Tic Tac Toe game that:

Provides a 3×3 game board.
Allows two players to enter their moves.
Checks whether a player has won the game.
Detects when the game ends in a draw.
Prevents players from selecting an already occupied position.
Displays the current game board after every move.

This project helps in understanding basic Python programming concepts such as lists, functions, loops, conditional statements, user input, and logical operations.
